# Правила работы с проектом (CS 1.6)

Проект: сервер CS 1.6 под Windows на закреплённом стеке — HLDS 8684, ReHLDS 3.15.0.896, ReGameDLL 5.30.0.814, Metamod-R 1.3.0.149, AMX Mod X 1.10.0.5484, ReAPI 5.29.0.358. Версии не меняются без отдельного решения. Все скиллы набора проверены на этих версиях. Если в папке сервера версии окажутся другими — сверяйся с её файлами, а не с текстом скиллов.

## Перед написанием кода

Запрос может быть любой: одна фраза, без подробностей, своими словами. Это нормально. Разбирать его — работа агента, а не пользователя.

Всегда три шага:

1. Разложить запрос на темы: что в нём затронуто — ресурсы и модели, состояние игрока, меню, команды и права, хранение данных, производительность, сборка, окружение сервера, версии.
2. Прочитать все скиллы, подходящие к этим темам. Если тема задевает несколько скиллов — читать все.
3. Первой строкой ответа назвать прочитанные скиллы. Только потом код.

Если в задаче по CS 1.6 с кодом ни один подходящий скилл не назван — значит код написан по памяти, и принимать его нельзя. На ответы без кода и на задачи вне CS 1.6 это правило не распространяется.

Таблицы ниже — подсказка, а не полный список. Чего в них нет — раскладывать самому.

| Если задача про | Прочитать скилл |
| --- | --- |
| любая задача по CS 1.6 — с чего начать | `cs16-router` |
| функции AMXX, устаревшие объявления, перенос кода из SA-MP | `amxx-api` |

## Жёсткие требования

1. Код собирается с `0 errors, 0 warnings` и `debug >= 1`, то есть без флага `-d0`.
2. Ни один запрет из прочитанных скиллов не нарушается. Запреты сформулированы как запреты намеренно.
3. Не использовать объявления, помеченные в AMX Mod X как deprecated.
4. Сигнатурные хуки и Orpheu запрещены, вместо них — цепочки ReAPI (владелец правила — `stack-and-pin`, «Жёсткие запреты» п.5 и «Решения проекта» п.1).
5. Не выдавать чтение кода за проверку на живом сервере. Если факт не подтверждён замером, так и сказать.
6. Первой строкой ответа назвать скиллы, прочитанные для этой задачи.
