# Как выбирать скиллы

Стек: HLDS 8684, ReHLDS 3.15.0.896, ReGameDLL 5.30.0.814, Metamod-R 1.3.0.149, AMX Mod X 1.10.0.5484, ReAPI 5.29.0.358. Все скиллы набора проверены на этих версиях. Если в папке сервера версии другие — сверяйся с её файлами, а не с текстом скиллов.

Это входная точка набора. Она не содержит правил о коде — она говорит, какие правила прочитать перед работой.

## Обязательное правило

Перед любой работой по CS 1.6 открыть таблицу «задача → скилл» в файле AGENTS.md в корне проекта и прочитать все скиллы, подходящие к задаче. Если задача задевает несколько тем — прочитать все.

Не считать знание API из памяти заменой чтению скилла. Скилл загружается в текущей задаче, а не «когда-то раньше».

## Порядок

Новая функциональность:

1. скиллы по темам задачи (таблица в AGENTS.md);
2. `amxx-api`, если в задаче есть вызовы функций AMXX;
3. `build` перед сборкой;
4. `diagnostics-and-method`, если что-то не заработало.

Разбор сбоя:

1. `diagnostics-and-method`;
2. скиллы по темам, которых касается сбой;
3. `amxx-api`, если сбой в вызове функции.

## Короткий запрос

Пользователь пишет по-бытовому: «хочу меню ножей», «сделай магазин», «сервер падает». Технические подробности он не пишет, и требовать их нельзя — разобрать формулировку на темы обязан агент.

1. Найти запрос в таблице простых фраз в AGENTS.md.
2. Если фразы нет — разложить её на темы и взять все подходящие скиллы.
3. Назвать прочитанные скиллы в ответе до первой строки кода.

## Чего не делать

- Не пропускать скилл потому, что тема уже упоминалась в разговоре.
- Не пропускать скилл потому, что задача выглядит маленькой.
- Не пропускать скилл потому, что реализацию можно написать сразу.
- Не загружать скиллы, не относящиеся к задаче: набор берётся по минимуму, но ничего подходящего не выбрасывается.

- Не ограничиваться общими скиллами, когда в таблице есть скилл по предметной области. Задача про зомби — это не только прекэш и сущности: `zombie-plague` обязателен.

## Проверка перед выдачей кода

1. Названы скиллы, которые прочитаны для этой задачи.
2. Для каждого названного скилла видно, какое его правило применено в коде.
3. Не выдумывать факт чтения скилла, если он не читался. *(доказательство: не применимо)*
