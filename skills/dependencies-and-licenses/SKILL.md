# Сторонние проекты и лицензии

Стек: HLDS 8684, ReHLDS 3.15.0.896, ReGameDLL 5.30.0.814, Metamod-R 1.3.0.149, AMX Mod X 1.10.0.5484, ReAPI 5.29.0.358. Правила проверены на этих версиях. Если в папке сервера версии другие — сверяйся с её файлами, а не с этим текстом. Пометка в скобках у правила говорит, чем оно подтверждено; искать по ней ничего не нужно. Полная таблица проверок — в `references/evidence.md`.

## Когда применять

- оценка чужого проекта, плагина или фреймворка
- вопрос лицензии и юридической чистоты
- решение брать или не брать чужой код

## Когда не применять

- версии закреплённого стека
- механика установки
- код плагина

## Жёсткие запреты

Нарушение любого пункта либо убивает сервер, либо тихо портит данные.

1. **Не переиспользовать код без лицензии** — AmxxModularEcosystem (около 30 репозиториев), AMXX Builder, NextClient, hlds-builds и Advanced Client Checker — ни у одного нет лицензии, проверено через GitHub API. Брать можно идею архитектуры, не код. *(доказательство: официальный источник)*
2. **Не брать Nova Pawn Compiler в production** — Версия 0.6.x, релизов нет, в истории коммитов правки вида «предотвратить падение компилятора». Компилятор — тот инструмент, ошибка которого тихо портит результат. Наблюдать, не брать. *(доказательство: официальный источник)*
3. **NextClient не использовать** — Клиентская зависимость (мод должен установить каждый игрок), лицензии нет, 50 открытых issues, предупреждение автора о ложных срабатываниях антивирусов, требование ровно engine 8684. *(доказательство: официальный источник)*
4. **Zombie Plague Enterprise не рассматривать** — Требует Linux. *(доказательство: не применимо)*
5. **Zombie-фреймворк попадает в Skills только после подтверждения на живом сервере** — Допускается только проверенное на живом сервере. ZP 5.0.8a это условие выполнил: прогоны 1–9, чистая база установлена и принята. Остальные зомби-фреймворки условия не выполнили и в Skills не попадают. *(доказательство: замер на живом сервере)*
6. **Приватные и платные сборки ZP не брать** — Belonard: по данным Dr.Web 39 % серверов CS 1.6 заражены, вектор — приватные сборки. Готовая сборка целиком с бинарниками — тот же вектор. *(доказательство: официальный источник)*

## Как делать правильно

1. **Артефакты брать только со страниц релизов upstream** — hlds.run — класс C: проверенные факты хранятся в каноническом документе, а не в базе знаний сообщества. *(доказательство: официальный источник)*

## Решения проекта

Не пересматриваются без новой проверки.

1. **ZP 5.0.8a — база проекта, а не oracle** — Решение 18.09.2026 (канон §17). Собирается 76 из 76 на AMXX 1.10.0.5484, лицензия GPL-3.0 подтверждена, runtime подтверждён прогонами 1–9 на живом сервере. Прежняя формулировка «только как oracle, не как базу» снята 20.09.2026: оба её основания оказались неверны. *(доказательство: замер на живом сервере; канон §17)*
2. **Правило допуска в Skills: любой намёк на проблему — отказ, а не пометка на будущее** — Установлено решением пользователя 18.09.2026: база Skills для OpenCode-агента содержит только проверенное. *(доказательство: не применимо)*

## Что проверять и помнить

1. **hlds-builds использовать только как fallback** — Лицензии нет: это перепубликация бинарников Valve. Основной путь — официальный архив с проверкой sha256. *(доказательство: официальный источник)*
2. **Два похожих репозитория fl0werD различать по лицензии** — `fl0werD/rezombie` (ReZombie, коммит `fa28fc01bf5d`, 05.02.2024) — GPL-3.0, единственный лицензированный современный зомби-фреймворк. `fl0werD/rezombieplague` (ReZP, коммит `f9b0c473f285`, 27.02.2021, 69 `.sma`, 12 853 строки) — лицензии **нет**: код брать нельзя, допустима только архитектура — слои API → ядро → контент, объекты на хендлах со свойствами, пары `_pre`/`_post`. *(доказательство: чтение репозиториев)*

## Проверка перед выдачей кода

1. Сборка: `0 errors, 0 warnings`, `debug >= 1` (без `-d0`).
2. Ни одно правило из раздела «Жёсткие запреты» не нарушено.
3. У каждого правила, попавшего в код, есть источник в этом файле.
